# Fokus dýchanie

Jednoduchá webová aplikácia pre počítač aj mobil:

- odpočítava 15-minútové pracovné okná,
- na konci okna pošle upozornenie,
- zobrazí vedené dýchanie: nádych na 4 doby, výdych na 4 doby.

## Spustenie

Stačí otvoriť `index.html` v prehliadači.

Pre lepšiu spoľahlivosť notifikácií môžeš spustiť lokálny server:

```bash
python3 -m http.server 8080
```

Potom otvor `http://localhost:8080`.
